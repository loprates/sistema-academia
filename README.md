# Sistema Academia

Sistema simples de academia feito em Python.

## O que o sistema faz

- Cadastrar aluno
- Listar alunos
- Registrar presença
- Remover presença
- Alterar matrícula
- Excluir aluno
- Validar CPF
- Não permite CPF repetido
- Gera ID automaticamente
- Salva os dados no `alunos.json`

## Atividades

- Musculação
- Pilates
- Zumba

## Matrícula

- Ativo
- Inativo

## Menu

1 - Cadastrar aluno
2 - Listar alunos
3 - Registrar presença
4 - Excluir aluno
0 - Sair

## Tecnologias

- Python
- JSON

## Como executar

Clone o projeto:

git clone https://github.com/loprates/sistema-academia.git

Entre na pasta:

cd sistema-academia

Execute:

python main.py
